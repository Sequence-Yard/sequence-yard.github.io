2. ビートを作る

  1. PLAY を押して再生します。
  2. ステップをタップして ON / OFF します（指を離したときに切り替わります）。
  3. 違う音を使うときは、トラック名かパッドをタップして選びます。

ジャンルのテンプレートから始める

LOAD →「Templates…」で、10 ジャンル（Hip-Hop・Trap・Lo-Fi・House・Techno・Drum & Bass・Funk・Rock・Reggaeton・Afrobeats）の定番のビートを今のパターン番号に入れられます。BPM と SWING もそのジャンルに合わせて変わります。

  • BASIC = 基本の形、VARI（VARIATION）= 少し変化をつけた形、FILL = 小節の終わりのおかず。
  • ALL 3 は今の番号から 3 つ続けて入れます。SONG で「BASIC ×3 → FILL ×1」のように並べると曲らしくなります。
  • BANK A の 8 トラック（kick〜tom lo）を使います。入れる先に内容があるときは確認が出ます。↶ で戻せます（TEMPO が GLOBAL のときは BPM は戻りません）。

デモソングを聴く

LOAD →「Demo songs…」で、DBR-1 の機能だけで作った 3 曲を読み込めます。読み込んだら PLAY で最後まで流れます（PLAY モードは SONG）。オートメーション（AUTO）、FX シーン、パターンごとのテンポ、ピッチのロックで作ったベースラインなど、どう作られているかを見ながら聴けます。

曲内容
Sequence Yardテクノ（134 BPM）。長さの違う無機質なシーケンス（12・10・9・7・5 ステップ）が 4 つ打ちとずれながら重なり、アシッドの線とダブのコードが動く（トラックごとの長さ → 3）
Yard Lightsハウス（124 BPM）→ ダブステップ（140 BPM）。フィルターの開閉、コードのパン、ワブルベース
Iron Yardアンビエント（100 BPM）→ インダストリアル（130 BPM）。深いリバーブ・ディレイ、テープのように揺れるディレイ、歪み
  • プロジェクトとして読み込むので、今のパターン・キット・BPM はすべて置き換わります（確認が出ます。↶ で戻せます）。残したい内容は先に SAVE してください。
  • 曲の音（47 音）は SOUND の LOAD の一覧（DEMO · 曲名）にもあり、自分の曲に使えます。デモソングは最後まで再生すると止まります（SONG タブの → ONCE）。

なぞって入力

  • 横になぞる: 同じトラックの複数のステップをまとめて ON / OFF。SWIPE の間隔（1/16・1/8・3/16・1/4・1/2）ごとに点灯します。
  • 縦になぞる: 同じステップ（同じタイミング）の複数のトラックをまとめて ON / OFF。
  • GAPS を ON にすると、なぞった範囲で間隔に当たらないステップを消します。
  • なぞり始めのステップが OFF なら点け、ON なら消します。なぞり 1 回が ↶ 1 回分です。

音の強さ（ベロシティ）

ステップを長押しすると振動します。そのまま上下にドラッグすると強さ（0〜127）が変わります。VELOCITY タブでは選択中のトラックの 16 ステップ分をまとめて編集できます。

長さとページ

LEN をタップすると 16 → 32 → 48 → 64 ステップと変わります。長くすると、今の内容をくり返して埋めます。1〜4 のボタンで表示するページを切り替えます（再生中のページには点が付きます）。ページの長押しで、そのページ（A / B 全トラック）のコピー / ペースト / 消去ができます。

FOLLOW を ON にすると、再生中は表示するページが再生位置に付いていきます（演奏向け）。OFF のときは選んだページのままです（打ち込み向け）。

スウィング

SWING を横にドラッグして 0〜100 を設定します。裏の 16 分音符が遅れて、跳ねたノリになります。パターンごとの設定です。

4. パッドとリアルタイム録音

パッドを叩くとその音が鳴り、そのトラックが選択されます（別のバンクならバンクも切り替わります）。

録音のしかた

  1. REC を押して点灯させます。
  2. PLAY を押すと、1 小節のカウントイン（再生位置が赤く光る）のあとに録音が始まります。メトロノームが ON ならクリックも鳴ります。
  3. パッドを叩くと、いちばん近いステップに記録されます（音が少し遅れて聞こえる分は自動で補正）。
  • カウントインの最後の半ステップ以内に叩いた音は、1 ステップ目に記録されます。
  • 小節の最後で次の頭を狙って叩いた音は、次に鳴るパターン（切り替え待ち・ソングの次の行）の頭に記録されます。
  • 停止中は REC が点灯していても記録されません。

パッドの強さ

タッチパネルは押す強さを検出できないため、VELOCITY タブの下段で選びます。FIXED = いつも同じ強さ（値は右のスライダー）、POSITION = パッドの上の方を叩くほど強く、下の方ほど弱くなります。

録音して使う（サンプリング）

SOUND タブの LOAD →「● Record (mic / audio input)…」で、マイクやオーディオインターフェースから録った音を、選択中のトラックに入れられます。初めて開いたときはマイクの使用の許可を求められます（録音はこの画面でだけ使い、録った音は端末の外へ送りません）。

  1. 入力を選ぶ: IN で内蔵マイク / USB の機器（オーディオインターフェースなど）。CH で録るチャンネルを選びます。ステレオの機器は L+R / L / R、3 チャンネル以上の機器は 1+2 / 3+4 / …（2 つを混ぜて録る）か、1 / 2 / …（1 チャンネルだけ）。レベルメーターで大きさを確かめます（右端が赤くなったら音が割れています）。
  2. 録る: ● REC で録り始め、■ STOP で止めます（最長 60 秒）。AUTO（−40 / −30 / −20dB）にすると ● ARM → 音がメーターの線を超えたところから自動で録り始めます。直前 0.1 秒も残ります。ARM を押した直後の 0.4 秒は、タップの音で始まらないよう無視します。待っている間に雑音だけで線を超えてしまうときは、AUTO を大きい値にしてください。▶ PATTERN でパターンを鳴らしながら録ることもできます。
  3. 整える: 波形の黄色いつまみをドラッグして使う範囲を選びます（つまみ以外をなぞると新しく選択、タップすると近い方のつまみがそこへ移ります）。
ボタンはたらき
▶ PLAY選んだ範囲を試聴
ZOOM選んだ範囲を拡大して表示（細かく合わせるとき）。全体を選んでいるときは頭のまわりを拡大。波形は 2 本指でピンチすると拡大・縮小、2 本指で横に動かすとスクロールできます。波形の下の方に秒の目盛りが出て、拡大すると細かく（最小 1/1000 秒）なります。拡大中は波形の下にスクロールバー（全体の小さな波形と、いま見ている範囲の枠）が出て、枠をドラッグすると見る位置を動かせます（枠の外をタップするとそこへ移動）
TRIM前後の無音を切る
DENOISEずっと鳴っている背景の雑音（エアコン・ファン・サー音など）を減らします。録った音のうち静かな部分から雑音の音色を自動で調べるので、音の前後に少し無音を入れて録るとよく効きます。効き方は弱めで、音の余韻を残します。足りなければもう一度押すとさらに減ります（かけすぎると音もやせます。そのときは UNDO で戻せます）
CROP選んだ範囲だけを残す
NORMALIZE選んだ範囲のいちばん大きい所がほぼ最大になるよう、その範囲の音量を上げる（もう最大なら「Already at full level」と出て何もしません）
FADE IN / FADE OUT選んだ範囲を徐々に大きく / 小さくする
REVERSE選んだ範囲を逆向きにする
↶ UNDO直前の編集を取り消す
RATE / BIT（下の段）トラックに入れるときにサンプルレート（周波数。そのまま / 32k / 26k / 22k / 12k / 8k）とビット数（16 / 12 / 8）を下げ、昔のサンプラーのようなザラッとした音にします。PLAY の試聴にも反映されます。録った音そのものは変わりません
● NEW TAKE録り直す（今の録音は捨てる）

名前を付けて Use on A01（選択中のトラック）を押すと、選んだ範囲がそのトラックの音になります。保存フォルダを選んでいれば DBR-1/Samples にも WAV で保存されるので、ほかのプロジェクトでも使えます。✕ で閉じると録音は使わずに終わります。

録音中に入力の音を聞く（モニター）機能はありません。オーディオインターフェースのダイレクトモニターを使ってください。録音中にほかのアプリに切り替えると、そこで録音を止めます（録れた分は残ります）。録った音があるときは、つまみを動かそうとして誤って「戻る」の操作になっても録った音が消えないよう、「戻る」は 2 回続けたときだけ画面を閉じます（✕ はすぐ閉じます）。
録音したり読み込んだりする音（曲・放送・他人の作品など）の著作権などの権利は、利用者の責任で扱ってください。作った曲を公開・配布するときは、使った音の権利を確認してください。

FILTER タブ

  • Filter（選択中のトラック）: OFF / LP12 / LP24 / HP12 / HP24 / BP / NOTCH、cutoff（周波数）、reso（強調）。
  • Master（全体フィルターの設定）: LP / HP か BP、12dB / 24dB、reso、AUTO RETURN（指を離すと中央に戻る）。

ミキサー（音量・定位の仕上げ）

表示中のバンクの 8 トラックと MASTER を並べ、全体のバランスをまとめて整える画面です。タブレットはヘッダーの MIX でステップの画面と切り替え、スマートフォンは左の MIX で開きます。もう一方のバンクは BANK A / B で切り替えます。

部品操作はたらき
トラック名タップそのトラックを選択（音は出ません）
EQ（HI / MID / LO）上下にドラッグ / ダブルタップ高音（8kHz〜）・中音（1kHz 付近）・低音（100Hz 以下）を ±12dB で上げ下げ。上へ動かすと強く、ダブルタップで 0。スマートフォンは右上の EQ でフェーダーと切り替えて表示します
pan横にドラッグ / ダブルタップ左右の位置。ダブルタップで C（中央）
フェーダー上下にドラッグ / ダブルタップ音量（0〜127）。触った所へ飛ばず、動かした分だけ変わります。ダブルタップで 100（初期値）
メーター—そのトラックの音の大きさ（音量・pan をかけた後、エフェクトの前）。−6dB より上は黄色
S / Mタップソロ / ミュート（シーケンサの S / M と同じ）
MASTER上下にドラッグ / ダブルタップ全体の音量（0〜127、ダブルタップで 127）。メーターは出力の大きさ。出力の直前にリミッターがあり、音が重なって上限を超えそうなときは自動で抑えるので歪みません。それでも抑えきれないほど大きいと CLIP が赤く点きます
EQ はトラックの音（キット）と一緒に保存されます。volume・pan・S / M は SOUND タブやシーケンサと同じ値です。どちらで変えても同じで、↶ で元に戻せます。MASTER はプロジェクトに保存され、書き出しにもかかります（↶ の対象外）。CLIP が点くとき（またはリミッターで音が詰まって聞こえるとき）は、MASTER か大きいトラックを下げてください。

6. エフェクト（FX）

  • REVERB（size / damp / mix / pre-dly）、DELAY（time / fdbk / mix / sync）、DIST（drive / tone / level）を上のボタンで選びます。それぞれ ON / OFF できます。
  • 下の wet は、選択中のトラックにそのエフェクトをかける量です（REVERB / DELAY はセンド量、DIST はかかり具合）。トラックごとに違う量を設定できます。
  • DELAY の sync は 1/4〜付点 8 分のテンポ同期。time を動かすと FREE（10ms〜1s）になります。
  • A / B: エフェクトの設定をパターンごとに 2 セット持てます。演奏中に切り替えられます。

7. 演奏用の機能（ROLL / REV / フィルター）

ボタン操作はたらき
ROLL押している間押した時点のステップから、選んだ長さをくり返します。画面の再生位置もくり返している範囲を回ります
1/4・1/8・1/16・1/32タップくり返す長さ。1/4 = 4 ステップ、1/16 = 1 ステップの連打、1/32 = 半分の間隔で連打
SLIPON / OFFROLL を離した後の続き方。OFF（既定）= ロールしていた位置の次から、ON = ロール中も裏で進んでいた本来の位置から
REV SEQON / OFFステップを逆の順番で再生
REV SNDON / OFFサンプルを後ろから再生（逆回転の音）

全体フィルター（FLT）

縦のフェーダーを中央から上へ動かすとハイパス（低音が削れる）、下へ動かすとローパス（高音が削れる）がかかります。中央付近は OFF です。設定は FILTER タブの Master で変えられます。

8. パターンとソング

  • パターンは 00〜99 の 100 個。各パターンがステップ・ベロシティ・長さ・スウィング・テンポ・エフェクトの設定・オートメーションを持ちます（音のキットは共通）。
  • 再生中にパターン番号を変えると、小節の終わりで切り替わります（待っている番号は枠が光ります）。停止中はすぐ切り替わります。
  • 長押しで、パターン全体のコピー / ペースト / 消去。

ソング（SONG タブ）

  • + ADD で今のパターンを行として追加します。各行は「パターン番号 × くり返す回数」（最大 99 行）。▲▼ で並べ替え、✕ で削除。
  • PLAY: SONG にしてから PLAY を押すと、並べた順に再生します。最後まで行ったときの動きは隣のボタンで選びます: ↻ LOOP = 先頭に戻ってくり返す（既定）、→ ONCE = 1 回で止める。この設定はプロジェクトに保存されます。

オートメーション（AUTO）

音量・パン・フィルター・EQ・センド量・FX・MASTER などを、パターンの中で動かせます。タブレットはヘッダーの AUTO、スマートフォンは左の AUTO で開きます。オートメーションはパターンごとに保存されます。

  • 上の段で対象を選びます: トラック（表示中のバンク）か FX / MASTER（リバーブ・ディレイ・ディストーションの設定、MASTER の音量、全体フィルター）。次の段で動かすパラメーターを選びます（赤い点 = オートメーションあり）。
  • LOCK（パラメーターロック）: ステップを上下にドラッグすると、そのステップの値が決まります。トラックでは、ロックした音はその値で鳴り、次に音（かロック）が来るまで続きます。ロックのない音は元の値に戻ります。FX / MASTER は、そのステップの間だけです。
  • DRAW: 線を描きます。描いた所は線の値、描いていない所は元の値（点線）です。1 ステップを 8 点で持ち、間はなめらかにつなぎます。描き方は 3 つ:
    • FREE = 指でなぞったとおり。
    • LINE = 触れた点から離した点までの直線（フェードイン・アウトや、だんだん開くフィルターに）。
    • WAVE = 波形。横にドラッグした範囲に、触れた点の高さと指の高さの間を行き来する波を描きます。形は SIN / TRI / SAW / SQR、1 周期の長さは 1/32〜1 BAR（1/8T は 3 連符）。ワブルベースやトレモロ、オートパンに。
    LINE と WAVE は、指を離すまで何度でも描き直せます（描き始める前の線に戻してから描きます）。
  • ERASE を点けてなぞると、なぞった所のロック・線を消します。CLEAR は選んだパラメーターのロックと線を全部消します。1〜4 で表示するページを切り替えます。
  • 優先の順は「動かしている最中のつまみ ＞ ロック ＞ 線 ＞ 元の値」です。
  • KNOB REC: REC を点けて再生中に画面のつまみ（または MIDI の CC）を動かすと、その動きを記録します。DRAW（既定）= 線として、LOCK = 近いステップのロックとして。OFF = 記録せず、いつものとおり値を変えます。記録している間、元の値は変わりません。
  • ↶（元に戻す）で取り消せます。CLEAR（ヘッダー）はステップと一緒にロックも消し、線は残します。
再生中は、オートメーションで動いている値が SOUND・FILTER・FX のつまみ、ミキサーの pan・EQ・フェーダー、全体フィルターのフェーダーにも表示されます。性能の低い端末で画面が重いときは、ロゴ（スマートフォンは ≡）のメニューの Animate automation を OFF にすると表示だけを止められます（音は変わりません。端末ごとの設定）。
ロックは Elektron のパラメーターロックに近い動きです。トラックごとの長さ（ポリリズム）を設定したトラックでは、DRAW の線の位置もそのトラックのステップで数えます。

9. テンポ

  • BPM をタップ: スライダー（20〜300）。細かい調整は −1 / +1。
  • BPM を長押し: 数字を直接入力。
  • TAP: リズムに合わせて何回か叩くと、その間隔からテンポを設定します（2 秒叩かないとリセット）。

パターンごとのテンポ（TEMPO: PATTERN / GLOBAL）

スライダーの下の TEMPO で、テンポの持ち方を選びます。

  • PATTERN（既定）: テンポはパターンごとです。BPM を変えると今のパターンのテンポになり、パターンを切り替えるとテンポも変わります（再生中は小節の終わりで、SONG でも行ごとに）。↶ でテンポも戻せます。
  • まだ何も入っていないパターンは、その前のテンポを引き継ぎ、音を入れた時点のテンポを覚えます。
  • GLOBAL: 全パターンで 1 つのテンポです。ライブでパターンを切り替えてもテンポを変えたくないときに。PATTERN に戻すと、各パターンのテンポに戻ります。
  • MIDI クロックを受けている（RECEIVE）間は、つないだ機器のテンポに従います。

作業中の内容は自動で端末に保存され、次に起動したときに元に戻ります。SAVE は、作品を別のファイルとして残したり、ほかの端末に渡したりするときに使います。

初めて保存するとき

保存先のフォルダを一度だけ選びます。選んだフォルダの中に DBR-1 フォルダ（Projects / Patterns / Kits / Samples）が作られます。

保存する

SAVE → 種類を選ぶと名前の入力画面が出ます。そのまま Save で保存できます。同じ名前のファイルがあるときは上書きしてよいか確認します。Other location… を選ぶと Android の保存画面から Google ドライブなどのクラウドにも保存できます。

読み込む・共有する

  • LOAD → 種類を選ぶと、フォルダの中のファイルが新しい順に並びます。名前をタップすると、上書きの確認のあとで読み込みます。
  • Share: メール・Google ドライブ・メッセージなどで送ります。✕: 削除（確認あり）。
  • Change folder: 保存先を変更。Other location…: クラウドなどほかの場所から開く。
  • パソコンから DBR-1/Samples に WAV などを入れておくと、SOUND の LOAD → From DBR-1/Samples… から読み込めます。

書き出し（音声・動画・MIDI。SNS・メールで共有）

  • 書き出しの途中でほかのアプリに切り替えても、最後まで作って保存します（その間は通知に「Exporting…」などが出ます）。Android 13 以降では、最初の書き出しのときに通知の許可を求められます。許可しなくても書き出しはできます（通知が出ないだけです）。

11. MIDI と USB オーディオ

USB-MIDI の機器（パッドコントローラー・キーボード・オーディオインターフェースの MIDI 端子など）を USB でつなぐと、自動で使えるようになります。設定はロゴ（スマートフォンは ≡）のメニューの MIDI…。

項目はたらき
IN（ON / OFF・CH）受けたノートでトラックを鳴らします。REC 中なら記録（ベロシティもそのまま）。CH = 受けるチャンネル（ALL / 1〜16）
NOTESノート番号とトラックの対応。PADS 36–51 = 36〜51 を A01〜B08 に順に。GM DRUMS = 一般的なドラムの番号（kick 36・snare 38・hat 42 …）。出力にも同じ対応を使います
OUT / OUT CH送り先の機器とチャンネル（既定 ch 10）。シーケンス・ROLL・パッドの音を送ります。DBR-1 の音とずれないよう、音の遅れの分だけ遅らせて送ります
CLOCKOFF / SEND（DBR-1 がマスター（親）になり、テンポと Start / Stop を送る）/ RECEIVE（つないだ機器に合わせて再生・停止。BPM も追従）
TIMINGMIDI を送るタイミングの取り方。APP（既定）= DBR-1 が時刻どおりに送る / SYSTEM = 送る時刻を付けて Android に任せる。どちらが揺れにくいかは端末によって違います（例: Lenovo Tab K11 は SYSTEM、REDMAGIC 9 Pro は APP のほうが安定）。相手の機器のテンポ表示が揺れるときは両方試してください。端末の設定として覚えます
PLAYRECEIVE のときだけ表示。FOLLOW（既定）= 相手の Start / Stop で再生・停止する / IGNORE = 再生・停止は DBR-1 の PLAY で行い、クロックとテンポだけ相手に合わせる
CCSEND = 画面のつまみを動かすと CC を送る（OUT の機器へ）。CC MAP… = CC とパラメーターの対応の一覧。LEARN = 割り当てを覚えさせる
TARGETトラックのパラメーターの CC がどのトラックを動かすか。SELECTED TRACK（既定）= 選択中のトラック（IN の CH で受け、OUT CH で送る）/ CH 1-16 = TRACKS: MIDI チャンネル 1〜16 がそれぞれトラック A01〜B08 に対応
Last input最後に受けたノートと、鳴らしたトラック。割り当ての確認に
マスター（CLOCK: SEND）として使うときの注意: スマートフォンやタブレットから送る MIDI クロックは、専用のハードウェアほど正確ではなく、わずかに揺れます。Android では MIDI の送信を OS が順番に処理するので、送る時刻が 1ms 前後ずれることがあります。相手の機器のテンポ表示が小数点以下で少し動くことがあります（例: 130 BPM で ±0.1〜0.4 程度。端末やオーディオインターフェースによって違います）。揺れが気になるときは TIMING の APP / SYSTEM を両方試してください。きっちり合わせたい場合は、相手の機器をマスターにして DBR-1 を RECEIVE にする方法もあります。DBR-1 の中の音のタイミングは音声の処理で刻んでいるので、この揺れの影響を受けません。

CC（つまみの割り当て）

コントローラーのつまみ（コントロールチェンジ）で、トラックの音量・パン・ピッチ・ディケイ・start / end・フィルター・EQ・センド量と、FX・MASTER・全体フィルターを動かせます。最初から次の番号が割り当ててあります。

トラックCCFX / MASTERCC
Volume / Pan / Pitch7 / 10 / 16Master volume / Master filter102 / 103
Decay / Start / End72 / 17 / 18Reverb size / damp / mix / pre-delay104 / 105 / 106 / 107
Filter cutoff / reso74 / 71Delay time / feedback / mix108 / 109 / 110
EQ low / mid / high20 / 21 / 22Dist drive / tone / level111 / 112 / 113
Reverb / Delay / Dist send91 / 92 / 94
  • LEARN: 押すと上に案内が出ます。画面のつまみを動かしてから、コントローラーのつまみを回すと、その CC が割り当てられます（続けて何個でも）。終わったら DONE。
  • CC MAP…: 番号のタップで直接入力、× で外す、Default で最初の割り当てに戻します。1 つの CC は 1 つのパラメーターだけを動かします。
  • SEND が ON なら、画面で動かしたつまみを CC で送ります（受けた CC は送り返しません）。SELECTED TRACK のときは、トラックを選び直すとそのトラックの値をまとめて送るので、表示のあるコントローラーと値がそろいます。
  • REC を点けて再生しているときに CC を受けると、オートメーションとして記録します（→ オートメーション）。

USB オーディオ

USB オーディオインターフェースや USB-C ヘッドホンは、挿すと自動でそちらから音が出ます。今の出力先は About（ロゴのメニュー）で確認できます。

マルチアウト（Audio I/O…）

出力が 3 チャンネル以上のオーディオインターフェース（例: Scarlett 6i6 は 6 チャンネル）なら、トラックごとに別の出力へ出して、ミキサーの別々のチャンネルで受けられます。ロゴ（スマートフォンは ≡）のメニューの Audio I/O… で設定します。

項目内容
MULTI OUTON にすると、機器の全チャンネルで出力します（OFF = いつものステレオ 1-2）。端末の設定として覚えます
MAIN OUTMAIN（全体の音・FX・メトロノーム）を出すペア。1-2（既定）/ 3-4 / 5-6 / …
TRACK OUTPUTS16 トラックそれぞれの出力先。タップして一覧から選びます: MAIN / ペア（3-4・5-6 …、ステレオ）/ 1 チャンネル（3・4・5・6 …、モノラル）。同じ出力に複数のトラックを出すと足されます。ミキサーでも、チャンネル名の下の出力先をタップして選べます（MAIN 以外を選ぶと MULTI OUT も自動で ON になります。MASTER の下では MAIN を出すペアを選べ、「Stereo only」を選ぶと MULTI OUT が OFF になります）
TEST TONE押した番号の出力だけに短い音（1kHz）を出します。違う出力から聞こえたら、オーディオインターフェースの中の振り分け（Scarlett なら Focusrite Control の Routing で、各出力が同じ番号の Playback を受けているか）を確かめてください
  • 別の出力へ出したトラックは、トラックのフィルター・ディストーション・EQ・音量・パン（1 チャンネルのときはパンなし）までかかり、MASTER（全体フィルター・MASTER の音量・リミッター）は通りません。リバーブ・ディレイのセンドは MAIN の FX へ送られます。
  • マルチアウト中は OS のミキサーを通らない出力になるため、音の遅れが少し増えます（Lenovo Tab K11 + Scarlett 6i6 で約 21ms → 28ms）。書き出し・録音（RECORD）は MAIN の音だけです。
  • 機器を外すと自動でステレオに戻り、もう一度つなぐとマルチアウトに戻ります。

12. 困ったとき

こんなとき確かめること
叩いてから音が出るまで遅れるBluetooth のイヤホン・スピーカーは大きく遅れます。有線のヘッドホンか本体のスピーカー、USB オーディオを使ってください。遅れの目安は About の「Output latency」に出ます（端末によって 20〜60ms 程度）
音が途切れるAbout の「underruns」が増えていないか。ほかのアプリを閉じると改善することがあります
保存したファイルが一覧に出ないLOAD の一覧の上に表示されているフォルダが保存先と同じか。Change folder で選び直せます
MIDI 機器が反応しないMIDI… の Connected に機器名が出ているか、IN が ON か、CH が合っているか。Last input で受けた内容を確認できます
操作を間違えた↶（元に戻す）で最大 100 回まで戻せます。TEMPO が GLOBAL のときの BPM・再生・パターン番号の移動・端末の設定は対象外です

アプリのバージョン・オープンソースライセンスは、ロゴ（スマートフォンは ≡）のメニューの About で確認できます。

MIDI・オーディオ

項目仕様
MIDI 入力USB-MIDI。ノートオンでトラックを鳴らす・録音（ベロシティ付き）。チャンネル ALL / 1〜16
MIDI 出力USB-MIDI 1 台。シーケンス・ロール・パッドをノートで送る（既定 10ch、ノートオフは 80ms 後）
ノートの割り当てPADS 36–51 / GM DRUMS
MIDI クロック送信（24 PPQN、Start / Stop）/ 受信（Start / Stop / テンポに追従。Start / Stop に従わない設定も可）
MIDI CC受信・送信。26 パラメーター（トラック 14・FX / MASTER 12）、割り当ての編集と LEARN。動かす先は選択中のトラック / MIDI チャンネル = トラック（TARGET）
マルチアウトUSB の機器の出力が 3ch 以上のとき、トラックごとに出力のペアか 1 チャンネル（モノラル）を選べる（最大 16ch）。MAIN のペアも選べる。チャンネルごとのテスト音
音声出力ステレオ、端末の出力レート（多くは 48kHz）。低遅延の経路で再生。USB オーディオに対応（挿すと自動で切り替え）

動作環境

項目仕様
OSAndroid 9 以降
メモリ3GB 以上を推奨（アプリの使用量は再生中に約 200MB）
画面横向き。タブレットは幅 1280dp 以上・高さ 600dp 以上、それ以外はスマートフォン用の画面
権限インターネット・位置情報は使いません。マイクはサンプリング画面でだけ使います。通知は書き出し・録音の間だけ出します。ファイルは選んだフォルダだけを使います

音の遅れは端末によって違います（確認した端末で約 20〜60ms）。Bluetooth の機器では大きく遅れます。
