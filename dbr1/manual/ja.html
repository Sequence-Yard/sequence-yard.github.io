2. ビートを作る

  1. PLAY を押して再生します。
  2. ステップをタップして ON / OFF します（指を離したときに切り替わります）。
  3. 違う音を使うときは、トラック名かパッドをタップして選びます。

ジャンルのテンプレートから始める

LOAD →「Templates…」で、10 ジャンル（Hip-Hop・Trap・Lo-Fi・House・Techno・Drum & Bass・Funk・Rock・Reggaeton・Afrobeats）の定番のビートを今のパターン番号に入れられます。BPM と SWING もそのジャンルに合わせて変わります。

  • BASIC = 基本の形、VARI（VARIATION）= 少し変化をつけた形、FILL = 小節の終わりのおかず（フィル）。
  • ALL 3 は今の番号から 3 つ続けて入れます。SONG で「BASIC ×3 → FILL ×1」のように並べると曲らしくなります。
  • BANK A の 8 トラック（kick〜tom lo）を使います。入れる先に内容があるときは確認が出ます。↶ で戻せます（TEMPO が GLOBAL のときは BPM は戻りません）。

なぞって入力

  • 横になぞる: 同じトラックの複数のステップをまとめて ON / OFF。SWIPE の間隔（1/16・1/8・3/16・1/4・1/2）ごとに点灯します。3 連符のトラックでは、同じ時間になるマス数があればその間隔（1/8 = 半拍、1/4 = 1 拍、1/2 = 2 拍）、なければ 3 連符の近い長さ（1/16 → 1/16T、3/16 → 1/4T）になります。1/16T のトラックの 1/8 は 2 マス空けて点灯します。1/8T のトラックでは半拍がマスに合わないので、1/16・1/8 はどちらも 1 マスごとです。
  • 縦になぞる: 同じステップ（同じタイミング）の複数のトラックをまとめて ON / OFF。
  • GAPS を ON にすると、なぞった範囲で間隔に当たらないステップを消します。
  • なぞり始めのステップが OFF なら点け、ON なら消します。なぞり 1 回が ↶ 1 回分です。

音の強さ（ベロシティ）

ステップを長押しすると振動します。そのまま上下にドラッグすると強さ（0〜127）が変わります。ゆっくり動かすと細かく、速く動かすほど大きく変わります（ミキサーの EQ のつまみも同じ）。VELOCITY タブでは選択中のトラックの 16 ステップ分をまとめて編集できます。

確率とラチェット

VELOCITY タブの上の 3 つのボタンで、バーで描くものを切り替えます。どれも選択中のトラックのステップごとの値で、パターンと一緒に保存されます（↶ で戻せます）。

ボタンはたらき
VELOCITY強さ（0〜127）
PROBABILITYそのステップが鳴る確率（0〜100%、5% 刻み）。毎回少しずつ違うフレーズになり、同じパターンでも飽きにくくなります。100% 未満のステップは右上に三角が付きます
RATCHET1 ステップを 1〜4 回に分けて鳴らします（ハイハットの細かい連打やロールに）。2 回以上のステップには上に回数の点が付きます。swing・3 連符のトラックでも、そのステップの長さを等分します

長さとページ

LEN をタップするとメニューが開き、パターンの長さを 1〜64 ステップ（1 ステップ = 16 分音符）で選べます。− / + で 1 ずつ、よく使う長さはボタンで選びます（ボタンで選ぶとメニューは閉じます）。長くすると、今の内容をくり返して埋めます。

4/4 以外の拍子（変拍子を含む）は、拍子に合わせて長さを変えます。3/4 拍子 = 12、7/8 拍子 = 14、5/4 拍子 = 20、7/4 拍子 = 28 ステップ。最後のページの長さの外のステップは薄く表示され、打ち込めません。メトロノームはパターンの頭で数え直すので、頭がいつも強拍になります。

1〜4 のボタンで表示するページを切り替えます（再生中のページには点が付きます）。ページの長押しで、そのページ（A / B 全トラック）のコピー / ペースト / 消去ができます。

FOLLOW を ON にすると、再生中は表示するページが再生位置に付いていきます（演奏向け）。OFF のときは選んだページのままです（打ち込み向け）。

スウィング

SWING を横にドラッグして 0〜100 を設定します。裏の 16 分音符が遅れて、跳ねたノリになります。パターンごとの設定です。

3 連符（Steps）

トラック名の長押しメニューの Steps で、そのトラックだけ 3 連符にできます。3 連符のトラックは 1 ページ（1 小節）の幅に 12 マス（1/8T）または 24 マス（1/16T）が並び、1 拍の幅に 3 / 6 マスが入るので、ほかのトラックの 16 分と縦の位置で見比べられます。名前の下に 1/8T・1/16T と表示されます。

  • 切り替えると、打ち込んだ音は時間の近いマスへ移ります（ロックは消えます。UNDO で戻せます）。描いたオートメーションは時間で持っているのでそのままです。
  • SWING は 16 分の裏だけにかかり、3 連符のタイミングは変わりません。
  • REC で叩くと、3 連符のマスの近いほうに記録します。VELOCITY タブ・オートメーションのロックも 3 連符のマスで並びます。
  • 変拍子と組み合わせられます（例: 7/8 拍子の 14 ステップを 1/8T にすると 10.5 マス分の長さになり、11 マス目は半分の長さでパターンの頭に戻ります）。3 連符のトラックでは Length（独自の長さ）は使えません。

自分で作った色は、パレットの Other… の横に表示されます。

4. パッドとリアルタイム録音

パッドを叩くとその音が鳴り、そのトラックが選択されます（別のバンクならバンクも切り替わります）。

録音のしかた

  1. REC を押して点灯させます。
  2. PLAY を押すと、1 小節のカウントイン（再生位置が赤く光る）のあとに録音が始まります。メトロノームが ON ならクリックも鳴ります。
  3. パッドを叩くと、いちばん近いステップに記録されます（音が少し遅れて聞こえる分は自動で補正）。
  • カウントインの最後の半ステップ以内に叩いた音は、1 ステップ目に記録されます。
  • 小節の最後で次の頭を狙って叩いた音は、次に鳴るパターン（切り替え待ち・ソングの次の行）の頭に記録されます。
  • 停止中は REC が点灯していても記録されません。

パッドの強さ

タッチパネルは押す強さを検出できないため、VELOCITY タブの下段で選びます。FIXED = いつも同じ強さ（値は右のスライダー）、POSITION = パッドの上の方を叩くほど強く、下の方ほど弱くなります。

音の管理画面（LOAD）

音の管理画面（SOUNDS）が開き、選択中のトラック（左上の「→ A01 …」）に入れる音を探せます。

上のタブ: USER（自分の音 = 保存フォルダの DBR-1/Samples の音声ファイルと DBR-1/Sounds の音）/ PRESET（内蔵の 52 音。BANK A / BANK B / EXTRA / POP / TRANCE）/ DEMO（デモソングの音。曲ごと）。

USER のタブ: ALL / UNSORTED（どのタブにも入れていない音）の右に、自分でタブを作って音を振り分けられます（+ TAB で作る、タブの長押しで名前の変更・並べ替え・削除。タブを消しても音は消えません）。各行の TAB ▾ で入れるタブを選びます。

各行: ▶ 試聴（トラックに入れずに原音を鳴らす。もう一度か ■ で止まる）/ 名前（タップでトラックへ。画面は閉じないので続けて聴き比べられます）/ カテゴリ（KICK・SNARE・HAT など。タップで選ぶ・New category… で自由な名前も。決めていない音は名前から推測したカテゴリを薄く表示）/ KEY（音の高さ。例: E2・C#5、和音は Dm9 など、音程のはっきりしない打楽器・環境音・ノイズは UNKNOWN。内蔵の音は作ったときの音名、自分の音は DBR-1 が音を調べて推定したキーを薄く表示（初めて開いたときに順に調べます。「…」は調べている途中）。タップでキーの画面: チューナー（推定の音名・ずれ（セント）・周波数）と Use …（オススメのキーにする）、OCTAVE と 12 音のボタン、UNKNOWN、Chord / other…（和音などを入力）、Auto（決めたキーを消して推定に戻す）。決めたキーは濃い色）/ 形式（WAV・MP3・AIFF など、DBRSND = サンプルと音の設定）/ お気に入り度 ★1〜5（同じ ★ をもう一度で 0）/ USER は ⋯ で共有・削除。

絞り込み: Search（名前・カテゴリ・グループ。キーは C#5 のように完全に一致したもの）/ CATEGORY / FORMAT / ★（★n 以上）/ SORT（並び: 一覧の順・名前・お気に入り度・カテゴリ・キー（低い音から）・新しい順）。

下の段（スマホは ⋯）: From file…（端末やクラウドのファイル）/ ● Record…（マイク・オーディオインターフェース・DBR-1 自身の音から録る。スライス・タイムストレッチもここ → 下）/ 右上の ✦ GENERATE…（波形を組み合わせて音を作る → 下）/ Save this sound…（選択中のトラックの音 = サンプルと音の設定（フィルター・INSERT・EQ など）を DBR-1/Sounds に保存。USER のタブを開いているとそのタブに入ります）/ Change folder（USER のとき。保存フォルダを選び直す）。.dbrsnd を入れるときは確認が出ます。↶ で戻せます。

音程のある内蔵の音には音名（例: D5。A4 = 440Hz、中央のド = C4）、和音の音にはコード名（例: Dm9）が書いてあります。~ が付いたもの（カウベル・コンガ）は、打楽器でいちばん近い音です。

※ 試聴は原音のまま鳴らします（トラックの pitch・フィルター・FX はかかりません）。カテゴリ・★・タブは保存フォルダの DBR-1/sound_library.json にも控えが残るので、アプリを入れ直しても戻ります

音を作る（GENERATE）

SOUND タブの LOAD の画面の右上 ✦ GENERATE…（スマートフォンは ✦ GEN）で、波形を組み合わせて自分の音を作れます。できた音はサンプリングの画面に渡して、選択中のトラックに入れます。プリセットにない音が欲しいときや、ベース・コード・パッド・ドラムを手早く作りたいときに使います。

画面はスクロールせず、左のタブでページを切り替えます（タブレット = WAVE A · B / KEY · AMP · FILTER、スマートフォン = WAVE A / WAVE B / KEY / AMP / FILTER。左手でタブ、右手で操作）。上の行にできた音（合成後）の波形・名前・長さと、🎲 RANDOM・▶ PLAY・HOLD・USE → EDIT… があります。HOLD を点けると、できた音をくり返し鳴らし続けます。そのままフィルターなどを動かすと、鳴っている位置のまま新しい音に切り替わるので、変化を聴きながら調整できます（もう一度押すか PLAY で止まります）。
WAVE A / B・AMP・FILTER の RESET で、そのパネルの設定を初期値に戻せます。KEY は鍵盤で根音を選び（コードの構成音も薄く光ります）、右の + / − でオクターブを変えます。コードの音は大譜表で表示します（タブレットは下、スマートフォンは右。基本形のみで転回形は扱いません。音名は音程どおり: Cm7 = C・E♭・G・B♭）。

  1. WAVE A で元になる波形を選ぶ: BASIC（SINE / TRI / SAW / SQUARE / PULSE）・SYNTH（SUPERSAW / FM / ORGAN / PLUCK / SYNC）・INST（生楽器っぽい音: PIANO / E.PIANO / GUITAR / BASS / STRINGS / MARIMBA / VIBES / BRASS / FLUTE / CHIME）・DRUM（KICK / SNARE / CLAP / HAT / TOM / RIM / BELL / ZAP）・NOISE（WHITE / PINK / BROWN）・SAMPLE（キットの 16 トラックの音か、保存フォルダの Samples の音。録音した音も使えます）
  2. WAVE B を on にすると、2 つ目の波形で A を変調するか、A に重ねます（右上で選ぶ）。FM（既定）= B で A の位相を揺らす（金属的・ベル・うなる音。B の TUNE で響きが変わります）/ RING = A と B を掛け合わせる（リングモジュレーション）/ AM = B で A の音量を揺らす / LAYER = 重ねる（例: SAW に 1 オクターブ下の SINE、キックにノイズ）。FM・RING・AM では B 自体は聞こえず、B の LEVEL が深さ（DEPTH）になります。どの波形の組み合わせにも掛かります（ドラム・サンプルを変調しても OK）
  3. それぞれ TUNE（±24 半音）・SHAPE（波形ごとに意味が変わります: FOLD = 折り返しのゆがみ、WIDTH = パルスの幅、DETUNE = スーパーソウの広がり、INDEX = FM の深さ、DRAWBAR = オルガンの倍音、DAMP = 弦のこもり、SYNC = シンクの強さ、TONE = 明るさ、BARK = エレピの硬さ、ENSEMBLE = ストリングスの広がり、HARD = マレットの硬さ、TREMOLO = ビブラフォンの揺れ、BRIGHT = ブラスの明るさ、BREATH = フルートの息、DECAY = ドラムの長さ、START = サンプルの再生開始位置）・LEVEL を決める（NOISE には TUNE がありません）
  4. AMP（ATTACK / LENGTH = 押している長さ / DECAY / SUSTAIN / RELEASE）と FILTER（OFF / LP / HP / BP、CUTOFF・RESO・ENV = エンベロープでカットオフを動かす量・ENV DEC）、DRIVE（歪み）を決める
  5. KEY / CHORD で音名（C〜B・OCTAVE 1〜6）と、単音（NOTE）かコード（OCT / 5 / MAJ / m / sus2 / sus4 / dim / aug / 7 / M7 / m7 / add9 / m9）を選ぶと、その音が鳴ります。▶ PLAY でもう一度鳴らせます
  6. 気に入ったら USE → EDIT…。サンプリングの画面で範囲・名前・KEY（音名・コード名が入っています）を確かめて、Use on … でトラックに入れます（Samples に WAV でも保存）
ドラムとノイズにはキーがありません（KEY / CHORD は使わず、ドラムの高さは TUNE で）。音程のある波形とドラムを重ねたときは、キー・コードは音程のある波形だけにかかります。
🎲 RANDOM で波形とつまみをでたらめに選んで鳴らします（キー・コードはそのまま）。思いがけない音から作り始めるのに便利です。
同じ設定なら毎回同じ音になります。設定はアプリを終えるまで残るので、閉じて開き直しても続きから作れます。サンプルの音は、元の音の高さを推定して（わからなければ C4 として）キーに合わせます。

録音して使う（サンプリング）

SOUND タブの LOAD →「● Record (mic / audio input)…」で、マイクやオーディオインターフェースから録った音を、選択中のトラックに入れられます。初めて開いたときはマイクの使用の許可を求められます（録音はこの画面でだけ使い、録った音は端末の外へ送りません）。DBR-1 自身の音を録る（リサンプリング）、録ったリズムを切って別々のパッドに入れる（スライス）、長さを変える（STRETCH）もこの画面で行います。

  1. 入力を選ぶ: IN で内蔵マイク / USB の機器（オーディオインターフェースなど）。CH で録るチャンネルを選びます。ステレオの機器は L+R / L / R、3 チャンネル以上の機器は 1+2 / 3+4 / …（2 つを混ぜて録る）か、1 / 2 / …（1 チャンネルだけ）。レベルメーターで大きさを確かめます（右端が赤くなったら音が割れているか、割れる寸前です）。周りの音が大きいときや音が大きすぎるときは、メーターの右の LEVEL（−30〜+12dB、既定 0dB）で録音レベルを下げます（小さい音は上げられます）。メーター・AUTO の判定・録る音のすべてにかかり、録っている最中にも変えられます。設定は端末に残ります。
    ※ Android ではアプリからマイクそのものの感度は変えられないため、受け取った音の大きさを変えています。マイクの段階で割れてしまう大きさの音は、LEVEL を下げても歪みが残ります（そのときはマイクから離してください）。
  2. 録る: ● REC で録り始め、■ STOP で止めます（最長 60 秒）。AUTO（−40 / −30 / −20dB）にすると ● ARM → 音がメーターの線を超えたところから自動で録り始めます。直前 0.1 秒も残ります。ARM を押した直後の 0.4 秒は、タップの音で始まらないよう無視します。待っている間に雑音だけで線を超えてしまうときは、AUTO の線を上げてください（−40 → −30 → −20dB）。▶ PATTERN でパターンを鳴らしながら録ることもできます。
  3. 整える: 波形の黄色いつまみをドラッグして使う範囲を選びます（つまみ以外をなぞると新しく選択、タップすると近い方のつまみがそこへ移ります）。

DBR-1 の音を録る（リサンプリング）

IN で DBR-1 output (resample) を選ぶと、DBR-1 自身が鳴らしている音（聞こえているとおり = エフェクト・MASTER・全体フィルターをかけた後）を録れます。パターンを 1 つの音にまとめてループとして使ったり、エフェクトをかけた音を新しい音にしたりできます（マイクの許可はいりません）。

  • BARS（OFF / 1 / 2 / 4 / 8）: 小節数を選んで ● REC N を押すと、パターンを頭から再生し、その最初の音から決めた小節数ぴったりを録って止まります（今のテンポで計算。きれいにループする長さになります）。1 小節は 4/4 の 16 ステップとして数えます。BARS を選ぶと、録る長さ（例:「1 BAR = 16 steps (4/4) at 120 BPM → records 2.00 s」）が REC の下に出ます。パターンの長さが小節と合わないとき（12 ステップなど）や、MIDI クロックを受けてテンポが外から決まるときは、ループの終わりとずれることがあるので、オレンジの注意が出ます。そのときは録った後に範囲を整えてください。
  • PAD（OFF / A01〜B08）: パッドを選んで ● REC PAD を押すと、パターンを止めてそのパッドを 1 回（最大の強さで）鳴らし、鳴らした瞬間から音が消えるまで（エフェクトの余韻を含む）を録って、自動で止まります（−60dB より小さいのが 0.3 秒続いた所で切る、最長 10 秒）。エフェクト・フィルター・EQ をかけた音を、そのまま 1 つの音にしたいときに。PAD を選んでいる間は BARS / AUTO は使いません。
  • BARS OFF のときはふつうの録音と同じく ● REC 〜 ■ STOP（AUTO も使えます）。▶ PATTERN や自分のパッド演奏も録れます。
  • 演奏の録音（書き出しの RECORD）中は使えません。

スライス（切って別々のパッドへ）

録ったリズムを音ごとに切り、それぞれを別のトラック（パッド）に入れます。編集の行の右端の SLICE ▸ で開きます（使う範囲 = 黄色いつまみの間を切ります）。

  • 開くと音の立ち上がり（キック・スネアなどの頭）で自動で切れ目が入ります。HITS · LOW / MID / HIGH を押すたびに感度が変わります（HIGH ほど細かく切ります）。
  • EVEN 4 / 8 / 16: 等分に切ります（ループを拍で分けるとき）。CLEAR: 切れ目を全部消す。
  • 波形をタップ = そのスライスを鳴らす、長押し（振動）= 切れ目を足す（切れ目の上なら消す）、切れ目をドラッグ = 動かす。最大 16 スライス。
  • ASSIGN TO PADS… で確認の画面が出ます。スライスごとに ▶ で聞きながら、入れる先のトラックを選びます（既定は選択中のトラックから順に。「Don't use」で入れない）。入れる先の今の音（置き換わる音）も表示され、同じトラックが 2 つあると赤くなって決められません。
  • 「Also make pattern NN…」にチェックすると、空いているパターンに、スライスを元のリズムどおりに鳴らすパターンを作ります（今のテンポで一番近いステップに置きます）。
  • スライスは 1 つずつ WAV（名前-1, 名前-2, …）として保存され、保存フォルダがあれば DBR-1/Samples にも入ります。入れた先のトラックの音の設定（音量・パン・ピッチ・フィルター・INSERT・EQ など）は初期値に戻ります（トラックの色・ミュート・ソロはそのまま）。↶（ヘッダーの UNDO）でまとめて元に戻せます。
録音中に入力の音を聞く（モニター）機能はありません。オーディオインターフェースのダイレクトモニターを使ってください。録音中にほかのアプリに切り替えると、そこで録音を止めます（録れた分は残ります）。録った音があるときは、つまみを動かそうとして誤って「戻る」の操作になっても録った音が消えないよう、「戻る」は 2 回続けたときだけ画面を閉じます（✕ はすぐ閉じます）。
録音したり読み込んだりする音（曲・放送・他人の作品など）の著作権などの権利は、利用者の責任で扱ってください。作った曲を公開・配布するときは、使った音の権利を確認してください。

FILTER タブ

  • Filter（選択中のトラック）: OFF / LP12 / LP24 / HP12 / HP24 / BP / NOTCH、cutoff（周波数）、reso（強調）。
  • Master（全体フィルターの設定）: LP / HP か BP、12dB / 24dB、reso、AUTO RETURN（指を離すと中央に戻る）。

ミキサー（音量・定位の仕上げ）

EQ はトラックの音（キット）と一緒に保存されます。volume・pan・S / M は SOUND タブやシーケンサと同じ値です。どちらで変えても同じで、↶ で元に戻せます。MASTER はプロジェクトに保存され、書き出しにもかかります（↶ の対象外）。CLIP が点くとき（またはリミッターで音が詰まって聞こえるとき）は、MASTER か大きいトラックを下げてください。

6. エフェクト（FX）

  • 上のボタンで REVERB（size / damp / mix / pre-dly）、DELAY（time / fdbk / mix / sync）、DIST（drive / tone / level）、INSERT（トラックごとのエフェクト）、MASTER（サイドチェイン・グルーコンプ）を選びます。● が点いているものが使われています。
  • REVERB / DELAY / DIST はそれぞれ ON / OFF でき、下の wet は選択中のトラックにかける量です（REVERB / DELAY はセンド量、DIST はかかり具合）。
  • DELAY の sync は 1/4〜付点 8 分のテンポ同期。time を動かすと FREE（10ms〜1s）になります。
  • SCENE A / B（REVERB / DELAY / DIST の名前の横）: REVERB / DELAY / DIST の設定をパターンごとに 2 セット持てます。演奏中に切り替えられます。
  • GLOBAL（ON / OFF スイッチの左）: 点灯させると、FX（シーン A / B・各トラックのセンド量）を全パターンで 1 つにします。演奏中にパターンを切り替えても FX が変わらず、どのパターンで動かしても全パターンに効きます。点けたときに今のパターンの FX を全パターンに写します（ほかのパターンに違う FX があれば確認が出ます）。消すと、そのときの FX のままパターンごとに戻ります。プロジェクトに保存されます。

INSERT（トラックごとのエフェクト）

トラックごとに 1 つ、エフェクトを選んでかけられます。フィルターの後・DIST の前にかかり、音（キット）と一緒に保存されます。つまみは 2 つと mix（原音と混ぜる量）。種類を変えると、つまみはその種類のおすすめの値になります。

CHORUSrate（0.1〜5Hz）・depthパッド・ベル・コードを広げる

MASTER（サイドチェイン・グルーコンプ）

  • Sidechain: trigger で選んだトラック（キックなど）が鳴るたびに、ほかのトラックの音量を depth だけ下げ、release（30〜630ms）で戻します。ハウス・テクノの「ポンピング」が作れます。音を分析せず鳴るタイミングで下げるので軽く、ミュート中のトラックでは下げません。
  • glue comp: 全体を軽く圧縮してまとまりを出します（0 = OFF）。リバーブ・ディレイの後、全体フィルターの前にかかります。
  • MASTER の設定はプロジェクトに保存されます（↶ の対象外。MASTER の音量と同じ）。書き出しにもかかります。

縦のフェーダーを中央から上へ動かすとハイパス（低音が削れる）、下へ動かすとローパス（高音が削れる）がかかります。中央付近は OFF です。設定は FILTER タブの Master で変えられます。

USER（好きなパラメーターをフェーダーで動かす）

フェーダーの上の名前（FLT）をタップするたびに、フェーダーの役割が FLT（全体フィルター）→ USER1 → USER2 → … → FLT と切り替わります（割り当てのない USER は飛ばします）。USER では、割り当てたパラメーターをまとめて足し引きできます（例: グラインダーのカットオフを開きながら、リバーブを深く、キックを小さく）。

  • 長押しで割り当ての画面が開きます。上のタブで USER を選び、+ USER で増やせます（USER1〜USER8）。+ Add で行を足し、行ごとに対象（16 トラックか FX / MASTER）・パラメーター・量（AMT: −100〜+100%）を選びます。1 つの USER に 16 まで（全トラックに 1 つずつ割り当てられます）。同じパラメーターを複数入れると量を足し合わせます。Delete でその USER を消します（後ろの番号が詰まります）。名前（USER1 など ✎）をタップすると、5 文字までの好きな名前を付けられます（例: BUILD・DROP）。フェーダーの上にもその名前が出ます。空にすると「USER 番号」に戻ります。割り当てがないまま USER にしようとしたときも、この画面が開きます。

  • フェーダーを中央から上げると量の分だけ足し、下げると引きます（量がマイナスの行は逆向き）。端まで動かすと、ちょうど量の分です。今の値（元の値・ロック・線）に足し引きするので、オートメーションの動きはそのまま残ります。上限・下限まで行ったら、それ以上は変わりません。
  • フェーダーの下には足し引きの量（+ / −）、動かしていないときは割り当ての数（×2 など）が出ます。FILTER タブの AUTO RETURN が ON なら、指を離すと中央（足し引きなし）に戻ります。役割を切り替えると、前の役割の効果は外れます。
  • 役割と割り当てはプロジェクトに保存されます（フェーダーの位置は保存しません。↶ の対象外）。トラックを入れ替えると、割り当ても付いていきます。音の書き出し（PATTERN / SONG）にはかからず、RECORD（演奏の録音・録画）では聞こえるとおりに残ります。

MIDI の部品

DBR-1 をマスターにして、外部のシンセやエフェクター、照明などを操作するための部品です。ボタンの ACTION の MIDI、フェーダー・ノブの CONTROLS の MIDI (external) で選びます。

  • CHANNEL: 送るチャンネル。複数選べます（数字のタップで足す / 外す。例: 1・3・10 に同じものを送る）。ALL は 1〜16 の全部（もう一度押すと 1 だけに戻る）。最後の 1 つは外せません。部品には「CH 1,3,10」「CH 1-4,10」（1〜4 と 10）のように番号で表示し、4 つ以上に分かれるときは「CH 1,3 +3」（ほかに 3 つ）と出ます。
  • CC NUMBER / NOTE / PROGRAM: 送る番号（0〜127）。ノートは音名も出ます（60 = C4）。
  • SEND TO: 送り先。複数選べます（タップで足す / 外す。1 つの部品で 2 台のシンセを同時に動かす、など）。MIDI OUTPUT（既定）= ロゴ（スマートフォンは ≡）の「MIDI…」の OUT で選んだ機器。ほかに、つながっている機器を部品ごとに選べます。出力が 2 つ以上ある MIDI インターフェースは「機器名 · OUT 2」のようにポートごとに出るので、シンセ A は OUT 1、エフェクター B は OUT 2、のように分けられます。送れないとき（出力を選んでいない・機器がつながっていない）は設定の画面に赤い字で出ます。
  • ON RELEASE の RETURN: CC・AFTERTOUCH は触る前の値へ、CC PAN・PITCH BEND は真ん中へ戻ります（ピッチベンドのホイールのように使えます）。
  • フェーダー・ノブの位置は保存しません（アプリを開き直すと 0、PAN・BEND は真ん中から）。同じ値は続けて送りません。
  • シーケンスの MIDI 出力（MIDI… の OUTPUT CHANNEL）とは別に送るので、シーケンスを外部の音源で鳴らしながら、別のチャンネルのつまみを動かせます。MIDI クロックを SEND にすれば、DBR-1 のテンポに機材を合わせられます。
この画面の MUTE・SOLO・シーン・エフェクトの ON / OFF は演奏の操作として扱い、↶（元に戻す）の履歴には入りません（長く演奏しても、それまでの編集を戻せます。あとで ↶ しても演奏した状態はそのまま）。状態はプロジェクトに保存されます。パラメーターの変更はふだんのつまみと同じく ↶ で戻せます。REC 中に再生しながらパラメーターを動かすと、MIDI の CC と同じようにオートメーションとして記録されます。

8. パターンとソング

  • パターンは 00〜99 の 100 個。各パターンがステップ・ベロシティ・長さ・スウィング・テンポ・エフェクトの設定・オートメーションを持ちます（音のキットは共通）。
  • 再生中にパターン番号を変えると、既定では小節（パターン）の終わりで切り替わります（待っている番号は枠が光ります）。停止中はすぐ切り替わります。
  • ロゴ（スマホは ≡）のメニューの Pattern switch で、再生中に切り替わるタイミングを選べます（タップで BAR → BEAT → NOW）。BAR（既定）= パターンの終わりで、次のパターンの頭から / BEAT = 次の拍で / NOW = 次の 16 分で。BEAT と NOW は再生位置をそのままに中身だけ入れ替えるので、リズムが途切れません（次のパターンのほうが短ければ、その長さで折り返した位置から）。パフォーマンス画面の PATTERN ボタンと合わせると、パターンを使ったリアルタイムの演奏ができます。
  • 長押しで、パターン全体のコピー / ペースト / 消去。Copy FX only / Paste FX only で、FX の設定（シーン A / B・センド量）だけを別のパターンへ写せます（ステップはそのまま、↶ で戻せます）。

ソング（SONG タブ）

  • + ADD で今のパターンを行として追加します。各行は「パターン番号 × くり返す回数」（最大 99 行）。▲▼ で並べ替え、✕ で削除。
  • PLAY: SONG にしてから PLAY を押すと、並べた順に再生します。最後まで行ったときの動きは隣のボタンで選びます: ↻ LOOP = 先頭に戻ってくり返す（既定）、→ ONCE = 1 回で止める。この設定はプロジェクトに保存されます。再生中に PATTERN ⇄ SONG を切り替えると、再生は止まります。

オートメーション（AUTO）

音量・パン・フィルター・EQ・センド量・FX・MASTER などを、パターンの中で動かせます。タブレットはヘッダーの AUTO、スマートフォンは左の AUTO で開きます。オートメーションはパターンごとに保存されます。

  • 対象: 一覧から選びます。タブレットは上の 1 行、スマートフォンは左の縦の一覧です（表示中のバンクの 8 トラックと FX / MASTER = リバーブ・ディレイ・ディストーションの設定、MASTER の音量、全体フィルター。スマートフォンでは「FX / MST」）。
  • パラメーターの一覧: SOUND・FILTER・EQ・SEND・INSERT（FX / MASTER では MASTER（音量・全体フィルター・サイドチェインの深さ・グルー）・REVERB・DELAY・DIST）に分けて並びます。各行の右に、パターン全体の線とロックが小さく出るので、どこに動きがあるか一目で分かります。タップで選びます。
  • 描くものは上のボタンで選びます（FREE / LINE / WAVE = 線、LOCK = ロック）:
    • LOCK: タップ = そのステップに、触れた高さでロック（パラメーターロック）。なぞると、指の通ったステップに続けてロックします。
    • FREE / LINE / WAVE: なぞると線を描きます（向きは関係ありません）。タップはその点だけ。
    • どちらでも、長押し（振動）してからなぞると、なぞった所のロックと線を消します。
    • 選んでいない方は薄く表示されます（ロックと線が重なっていても見分けられます）。同じステップにロックと線があると、ロックが優先です。
  • ロック: トラックでは、ロックした音はその値で鳴り、次の音（またはロック）まで続きます。ロックのない音は元の値に戻ります。FX / MASTER のロックはそのステップの間だけです。
  • 鳴っている音にも効く: pitch・decay・end（逆再生のときは start）は、鳴り始めだけでなく、音が鳴っている間も線・ロック・つまみの動きに合わせて変わります（長い音に線を描くと、鳴りながら音の高さがなめらかに変わります）。end を今鳴っている位置より前にすると、短くフェードして止まります。
    ※ pitch は、描いた線・つまみの動きでは半音の間の高さもとります（なめらかに上がり下がりする）。ロックは半音ちょうどにそろえるので、決まった音程にしたいステップはロックで指定してください
  • 線: 描いた所は線の値、描いていない所は元の値（点線）です。描く面のいちばん下の帯は 0 より下の余白で、ここを触っても 0 になります（画面の下端から上へのスワイプでホームに戻る端末でも、0 を描きやすいように）。1 ステップを 8 点で持ち、間はなめらかにつなぎます。形は 3 つ:
    • FREE = 指でなぞったとおり。
    • LINE = 触れた点から離した点までの直線（フェードイン・アウトや、だんだん開くフィルターに）。
    • WAVE = 波形。横にドラッグした範囲に、触れた点の高さと指の高さの間を行き来する波を描きます。WAVE を選ぶと 2 行目に形（SIN / TRI / SAW / SQR）と 1 周期の長さ（1/32〜1 BAR、1/8T = 8 分の 3 連符）が出ます。ワブルベース・トレモロ・オートパンに。
    LINE と WAVE は、指を離すまで何度でも描き直せます（描き始める前の線に戻してから描きます）。
  • 1〜4 で表示するページを切り替えます（パターンが 16 ステップより長いときに表示。スマートフォンでは FOLLOW は「FLW」）。FOLLOW を ON にすると、再生中は表示するページが再生位置に付いていきます（SEQ の FOLLOW と同じ設定で、どちらで切り替えても両方に効きます。指で描いている間はページを動かしません）。
  • ⋯: 「Clear（パラメーター名）」で選んだパラメーターのロックと線を全部消します。KNOB REC もここで選びます: REC を点けて再生中に画面のつまみ（または MIDI の CC）を動かすと、その動きを記録します。DRAW（既定）= 線として、LOCK = 近いステップのロックとして。OFF = 記録しない（つまみは普通に値を変えます）。記録している間、元の値は変わりません。
  • スマートフォン: 右上の FULL で全画面になり、上のボタン列と左のタブが消えて広く描けます。全画面では ▶ / ■（再生・停止）と EXIT（戻る）が右上に出ます。端末の「戻る」でも全画面をやめます。
  • 優先の順は「動かしている最中のつまみ ＞ ロック ＞ 線 ＞ 元の値」です（メインフェーダーの USER は、その結果に足し引きします）。
  • ↶（元に戻す）で取り消せます。CLEAR（ヘッダー）はステップと一緒にロックも消し、線は残します。
再生中は、オートメーションで動いている値が SOUND・FILTER・FX のつまみ、ミキサーの pan・EQ・フェーダー、全体フィルターのフェーダーにも表示されます。性能の低い端末で画面が重いときは、ロゴ（スマートフォンは ≡）のメニューの Animate automation を OFF にすると表示だけを止められます（音は変わりません。端末ごとの設定）。
ロックは Elektron のパラメーターロックに近い動きです。トラックごとの長さ（ポリリズム）を設定したトラックでは、DRAW の線の位置もそのトラックのステップで数えます。

9. テンポ

  • BPM をタップ: スライダー（20〜300）。細かい調整は −1 / +1。
  • BPM を長押し: 数字を直接入力。
  • TAP: リズムに合わせて何回か叩くと、その間隔からテンポを設定します（2 秒叩かないとリセット）。

パターンごとのテンポ（TEMPO: PATTERN / GLOBAL）

スライダーの下の TEMPO で、テンポの持ち方を選びます。

  • PATTERN（既定）: テンポはパターンごとです。BPM を変えると今のパターンのテンポになり、パターンを切り替えるとテンポも変わります（再生中はパターンが切り替わる所で = メニューの Pattern switch のとおり、SONG でも行ごとに）。↶ でテンポも戻せます。
  • まだ何も入っていないパターンは、その前のテンポを引き継ぎ、音を入れた時点のテンポを覚えます。
  • GLOBAL: 全パターンで 1 つのテンポです。ライブでパターンを切り替えてもテンポを変えたくないときに。PATTERN に戻すと、各パターンのテンポに戻ります。
  • MIDI クロックを受けている（RECEIVE）間は、つないだ機器のテンポに従います。

11. MIDI と USB オーディオ

USB-MIDI の機器（パッドコントローラー・キーボード・オーディオインターフェースの MIDI 端子など）を USB でつなぐと、自動で使えるようになります。設定はロゴ（スマートフォンは ≡）のメニューの MIDI…。

項目はたらき
IN（ON / OFF・CH）受けたノートでトラックを鳴らします。REC 中なら記録（ベロシティもそのまま）。CH = 受けるチャンネル（ALL / 1〜16）
NOTESノート番号とトラックの対応。PADS 36–51 = 36〜51 を A01〜B08 に順に。GM DRUMS = 一般的なドラムの番号（kick 36・snare 38・hat 42 …）。出力にも同じ対応を使います
THRU（ON / OFF）MIDI スルー。つないだ機器で弾いたもの（ノート・CC・ピッチベンドなど）を、そのまま OUT の機器へ送ります（チャンネルは元のまま）。OUT と同じ機器から来たものは、ふだんは送り返しません。クロックと SysEx は送りません。受けたノートで DBR-1 のトラックが鳴るのはそのままです。
☐ ALSO FROM OUT DEVICE（THRU が ON のとき）: チェックすると、OUT と同じ機器から来たものも送ります。1 台の MIDI インターフェースの IN に鍵盤、OUT に音源をつないでいるときはチェックしてください（しないと何も送られません）。
※ チェックしたまま、OUT にシンセを直接（インターフェースを通さずに）つなぐと、シンセの演奏がシンセ自身に戻り、二重に鳴ったり音が止まらなくなったりします。そのときはチェックを外すか、シンセのローカルコントロールを OFF に
※ 機器どうしをケーブルで輪のようにつなぐと、同じ音が繰り返し送られることがあります
OUT / OUT PORT / OUT CH送り先の機器とチャンネル（既定 ch 10）。出力が 2 つ以上ある機器（MIDI インターフェースなど）は OUT PORT で使うポートも選べます。シーケンス・ROLL・パッドの音を送ります。DBR-1 の音とずれないよう、音の遅れの分だけ遅らせて送ります
CLOCKOFF / SEND（DBR-1 がマスター（親）になり、テンポと Start / Stop を送る）/ RECEIVE（つないだ機器に合わせて再生・停止。BPM も追従）
TIMINGMIDI を送るタイミングの取り方。APP（既定）= DBR-1 が時刻どおりに送る / SYSTEM = 送る時刻を付けて Android に任せる。どちらが揺れにくいかは端末によって違います（例: Lenovo Tab K11 は SYSTEM、REDMAGIC 9 Pro は APP のほうが安定）。相手の機器のテンポ表示が揺れるときは両方試してください。端末の設定として覚えます
PLAYRECEIVE のときだけ表示。FOLLOW（既定）= 相手の Start / Stop で再生・停止する / IGNORE = 再生・停止は DBR-1 の PLAY で行い、クロックとテンポだけ相手に合わせる
CCSEND = 画面のつまみを動かすと CC を送る（OUT の機器へ）。CC MAP… = CC とパラメーターの対応の一覧。LEARN = 割り当てを覚えさせる
TARGETトラックのパラメーターの CC がどのトラックを動かすか。SELECTED TRACK（既定）= 選択中のトラック（IN の CH で受け、OUT CH で送る）/ CH 1-16 = TRACKS: MIDI チャンネル 1〜16 がそれぞれトラック A01〜B08 に対応
Last input最後に受けたノートと、鳴らしたトラック。割り当ての確認に
マスター（CLOCK: SEND）として使うときの注意: スマートフォンやタブレットから送る MIDI クロックは、専用のハードウェアほど正確ではなく、わずかに揺れます。Android では MIDI の送信を OS が順番に処理するので、送る時刻が 1ms 前後ずれることがあります。相手の機器のテンポ表示が小数点以下で少し動くことがあります（例: 130 BPM で ±0.1〜0.4 程度。端末やオーディオインターフェースによって違います）。揺れが気になるときは TIMING の APP / SYSTEM を両方試してください。きっちり合わせたい場合は、相手の機器をマスターにして DBR-1 を RECEIVE にする方法もあります。DBR-1 の中の音のタイミングは音声の処理で刻んでいるので、この揺れの影響を受けません。

USB オーディオ

USB オーディオインターフェースや USB-C ヘッドホンは、挿すと自動でそちらから音が出ます。今の出力先は About（ロゴのメニュー）で確認できます。

マルチアウト（Audio I/O…）

出力が 3 チャンネル以上のオーディオインターフェース（例: Scarlett 6i6 は 6 チャンネル）なら、トラックごとに別の出力へ出して、ミキサーの別々のチャンネルで受けられます。ロゴ（スマートフォンは ≡）のメニューの Audio I/O… で設定します。

  • 別の出力へ出したトラックは、トラックのフィルター・ディストーション・EQ・音量・パン（1 チャンネルのときはパンなし）までかかり、MASTER（全体フィルター・MASTER の音量・リミッター）は通りません。リバーブ・ディレイのセンドは MAIN の FX へ送られます。
  • ご注意: マルチアウトを使うと、音が遅れることがあります。端末によっては OS の低遅延の経路を通らず、大きく遅れます（例: REDMAGIC 9 Pro + Scarlett 6i6 で約 0.3 秒。ステレオなら約 0.02 秒）。パッドで演奏するときはステレオ（MULTI OUT OFF）、マルチアウトはミキサーへ別々に出す・録るときに、と使い分けてください。また端末とオーディオインターフェースの組み合わせによっては、音が出ない・ノイズが乗ることがあります。DBR-1 は Android 14 以降では機器を 48kHz で開くよう OS に頼みますが、それより前の Android では OS が機器の最高のサンプルレート（192kHz など）で開き、音が出ないことがあります（例: Lenovo Tab M10 3rd Gen + Scarlett 6i6。この端末はステレオでも同じで、DBR-1 以外のアプリでも音が出ません）。その場合は MULTI OUT を OFF（ステレオ）にしてください。
  • ジリジリというノイズや、音が少し遅く聞こえるときは、電源から来るノイズのこともあります。端末やインターフェースにつないでいる USB の給電（充電）ケーブルを外すと直ることがあります（Lenovo Tab K11 + Scarlett 6i6 で確認）。
  • 書き出し・録音（RECORD）は MAIN の音だけです。
  • 機器を外すと自動でステレオに戻り、もう一度つなぐとマルチアウトに戻ります。
